What Odin is, in one paragraph

Odin tracks each security rollout from purchase order to signed acceptance. Staff move a project through its stages; tasks, documents, risks and a dated plan hang off each project; reports and a signed sign-off close it. One Flask application serves the React screens and the data behind them, keeps everything in one SQLite database on the server, and a second process on the same server runs the scheduled work: reminders, alerts, backups and the weekly report.

Who uses itStaff (Admin, Member, Contributor, Viewer) and invited partners or customers (External) Where it runsOne Ubuntu VM, three Docker containers, reached only through a Cloudflare tunnel What it talks toMicrosoft 365 for mail, Teams and backups, Microsoft sign-in, a Teams webhook, Kibana. Only the webhook is usable today. Where data leavesEmails, Teams posts, PDFs, CSV exports, document downloads, the read-only API, backups, guest pages
